# Awwwards SOTD Builder

A Claude skill for designing and building award-caliber websites aimed at Awwwards Site of the Day: concept-first art direction, scroll-driven motion, performance and accessibility passes.

## Contents
- `SKILL.md`: the skill itself (workflow, rules, anti-patterns)
- `references/`: design, motion, tech stack, criteria, performance, QA guides
- `examples/starter-template/`: dependency-free starter with a scroll-driven hero, kinetic type and custom cursor

## Install
Copy this folder into your Claude skills directory (for Claude Code: `~/.claude/skills/awwwards-sotd-builder`), or upload it as a skill in Claude settings.

## Try the starter
    cd examples/starter-template
    python -m http.server 5173
